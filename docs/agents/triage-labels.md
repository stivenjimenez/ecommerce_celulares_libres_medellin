# Triage labels

Use these default labels as the status vocabulary in local spec and ticket files:

| Label             | Meaning                          |
| ----------------- | -------------------------------- |
| `needs-triage`    | Needs evaluation                 |
| `needs-info`      | Waiting for more information     |
| `ready-for-agent` | Specified and ready for an agent |
| `ready-for-human` | Requires human implementation    |
| `wontfix`         | Will not be actioned             |
